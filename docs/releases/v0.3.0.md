# CortexState 0.3.0

Inspectable, scoped memory for AI applications, with an optional native ranking core.

## Packages

- `cortexstate-0.3.0` — portable Python package; the Python scorer works without Rust.
- `cortexstate-client-0.3.0.tgz` — JavaScript ESM client and TypeScript declarations.
- `cortexstate_rank-0.3.0` — optional native BM25 batch scorer. Wheels are built for Python 3.10 and 3.12 on the Linux, Windows, and macOS GitHub runners; install the matching wheel alongside CortexState.
- Source archive — complete repository source at this release tag.

The native scorer is selected automatically when installed. Set `CORTEXSTATE_PYTHON_RANKER=1` before starting Python to use the reference implementation. No speedup is claimed; compare against your workload before choosing the native package.

## Changes

- Added a deterministic Rust BM25 batch scorer with a Python parity check.
- Bounded concurrent HTTP handlers and tightened request-length validation.
- Enabled SQLite WAL and explicit busy timeout settings; added indexes for expiry and erasure lookups.
- Added an original repository banner and aligned Python, JavaScript, and Rust package versions.

## Compatibility and limits

The HTTP API and Python memory methods remain compatible with the 0.2 developer preview. SQLite uses WAL mode; keep the database on local persistent storage, not a shared network filesystem. The bundled HTTP service remains intended for local or private use behind a reviewed gateway, not direct public exposure.
